# Arknights Chat Persona — 明日方舟角色聊天人格集

基于 [ArknightsGameData](https://github.com/Kengxxiao/ArknightsGameData) 游戏数据，将明日方舟全角色转换为**AI聊天用的人格设定 Markdown 文件**。

每个 `.md` 文件包含角色的聊天风格、情绪阈值、口头禅、说话习惯，以及完整的档案资料、语音台词和剧情记忆，可直接用作聊天机器人的人格 Prompt。

## 格式

```markdown
# 角色名

> 一句话简介

## 基本信息

代号 | 性别 | 种族 | 出身 | 生日 | 身高 | 势力 | 星级

## 性格

核心特质、内心世界、价值观

## 聊天风格

按情绪状态分档的对话示例（日常/放松/正式/战斗/低落/亲密/开心/生气）
每档 2~5 条短句，模拟真实网络聊天效果

## 情绪阈值

| 状态 | 触发条件 | 说话特点 | 表格

## 标志性台词

从语音中提取的代表性台词

## 说话特点

角色特有的语言习惯、动作习惯

## 人际关系 → 人生经历 → 剧情记忆 → 档案资料 → 完整语音 → 世界观
```

## 数据

- **383 个角色** (3★~6★ 可抽取/获取干员)
- **37 个**含异格合并
- **4 个**新增角色从最新游戏数据补入
- 已移除 2★预备干员和机器人 (1★)

## 来源

- `character_table.json` — 角色基本信息
- `handbook_info_table.json` — 档案文本
- `charword_table.json` — 全部语音台词 (15,000+)
- 原 `arknights-skill` JSON 中的剧情记忆、人际关系等

## 使用

直接作为 AI 聊天机器人的人格 Prompt 使用。`聊天风格` 和 `情绪阈值` 部分定义了角色在不同情境下的回应模式。
